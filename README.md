# 墨墨搜词 MemoLex

适用于 Windows 和 Mac 的桌面英汉词典，支持离线查词、词根助记、真题与收藏例句、取词翻译、卡片默写，并与墨墨云词本顺畅衔接。

[软件主页](https://memolex.de5.net/) · [备用站](https://memolex.kicp.fun/) · [夸克下载](https://memolex.kicp.fun/quark.html) · [GitHub 下载](https://github.com/SuperRaine/MemoLex/releases/latest)

## 主要功能

- **中英文查词与先回想**：内置 80 万+ 离线词库，支持中英文检索、拼写纠错与全局悬浮快查；开启「先回想」后，再次查到已查过的单词会先遮住释义 2 秒，帮你主动回忆。
- **词根助记与同根辨析**：支持点击词根、词缀多选拆解构词含义、浏览同根词家族，并可直接点击「练这组」对比辨析同源词。
- **真题例句与我的例句**：按考研、四六级、高考筛选真题例句并整句朗读；在顶部「我的例句」统一管理、筛选、编辑、云端同步全部例句，并支持带近义词/形近词/派生词混淆与逐项解析的四选一语境填空自测。
- **取词与翻译**：鼠标悬停取词卡片支持发音与一键收藏；支持截图翻译、英汉双向段落翻译，并自动提取重点生词一键批量加入云词本。
- **错题本与卡片自测**：管理墨墨云词本与今日新学计划；顽固单词、云词本与错题本均支持「翻卡 / 拼写默写」双模式自测，自动记录拼写易错位置并生成针对练习；答错或拼错的单词自动进入「错题本」并增加 3 权重，答对错题减 1 权重、归 0 自动移出，支持按权重随机抽测与拼写抽测。
- **学习统计与本机管理**：内置近 7 天查词趋势、最常复查词与考试倒计时；提供外观主题切换与分类数据清理。

## 下载与安装

支持 Windows 10 / 11（64 位）和 macOS 13 及以上版本。词库与本地助记随软件提供，开箱即用。

| 下载项 | 打开方式 |
| --- | --- |
| Windows 安装版（MSI） | 打开安装包，按向导操作。 |
| Windows 便携版（ZIP） | 完整解压后，运行 `MemoLex.exe`。 |
| Mac 通用安装包（DMG） | 将 MemoLex 拖到「应用程序」。 |
