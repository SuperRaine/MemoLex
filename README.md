# 墨墨搜词 MemoLex

适用于 Windows 和 Mac 的桌面英汉词典，支持离线查词、助记、真题例句和翻译。

[软件主页](https://memolex.de5.net/) · [备用站](https://memolex.kicp.fun/) · [夸克下载](https://memolex.kicp.fun/quark.html) · [GitHub 下载](https://github.com/SuperRaine/MemoLex/releases/latest)

## 主要功能

- **中英文查词**。输入英文查释义，或用中文找单词。
- **助记与例句**。点击助记中的词根和词缀查看含义，按考试类型查看真题例句。
- **取词与翻译**。鼠标取词后可在浮窗里收藏，支持截图翻译和段落翻译。
- **词本与学习**。管理云词本和今日待学，使用卡片自测复习顽固单词。

## 下载与安装

支持 Windows 10 / 11（64 位）和 macOS 13 及以上版本。词库和助记随软件提供。

| 下载项 | 打开方式 |
| --- | --- |
| Windows 安装版（MSI） | 打开安装包，按向导操作。 |
| Windows 便携版（ZIP） | 完整解压后，运行 `MemoLex.exe`。 |
| Mac 通用安装包（DMG） | 将 MemoLex 拖到「应用程序」。 |
