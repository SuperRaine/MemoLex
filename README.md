# 墨墨搜词 MemoLex

适用于 Windows 的英汉查词工具。支持离线查词、中文反查、助记和真题例句，也可以把查到的单词加入墨墨云词本或今日新学。

[下载软件](https://github.com/SuperRaine/MemoLex/releases/latest) · [详细使用说明](使用说明.md) · [问题反馈](https://github.com/SuperRaine/MemoLex/issues/new/choose)

## 下载与安装

目前公开版本为 **1.2.0**，支持 **Windows 10 / 11（64 位）**。

| 版本 | 使用方法 |
| --- | --- |
| [安装版](https://github.com/SuperRaine/MemoLex/releases/download/v1.2.0/MemoLex-1.2.0-Windows-x64-Setup.msi) | 下载后双击，按向导选择安装位置。 |
| [便携版](https://github.com/SuperRaine/MemoLex/releases/download/v1.2.0/MemoLex-1.2.0-Windows-x64.zip) | 解压整个压缩包，运行 `MemoLex/MemoLex.exe`。请保留同目录下的其他文件和 `data` 文件夹。 |

两种版本均自带运行环境、77 万余离线词条和本地助记，无需另装 .NET，也无需首次启动下载词库。离线查词不需要登录。

## 查词与阅读

在左侧搜索框输入英文单词或短语，按 **Enter** 查询。也可以直接输入中文含义，反查对应英文及同义词；完整匹配中文义项的结果优先显示。

词条页从上到下显示**释义、助记、真题例句**。点击其中的英文单词可以继续查词，再用标题栏的后退按钮返回原来的阅读位置。

- **助记**：点击「编辑助记」即可修改并保存到本机。登录后可以选择「同步到墨墨」；本地助记不会自动上传。账号云端有助记时，优先显示云端内容。内置助记仅覆盖部分词条。
- **真题例句**：可按考研、四级、六级和高考筛选，查看原文、译文及试卷来源。
- **相关词**：点击近义词、形近词、派生词或常用短语，查看释义并跳转查词。
- **最近查词**：在左侧重新打开查过的单词，或打开完整历史记录筛选、删除记录。

## 连接墨墨账号

离线查词可以直接使用。云词本、个人云端助记和今日新学需要连接自己的墨墨账号。

1. 点击标题栏右侧账号与设置，进入「墨墨账号」，点击官方登录。
2. 在墨墨官方页面使用手机号／邮箱与密码，或手机验证码登录。软件会自动保存授权。
3. 登录后，在左下角选择要使用的云词本；多个已登录账号可在账号设置中切换。

账号凭据使用 Windows 用户加密保存在本机，不随软件包分发。登录过期时会提示重新登录；也保留高级 Token 导入入口。

### 收藏与管理云词本

查词后点击「加入云词本」，即可收藏到左下角选中的词本。按钮显示已加入时，再次点击可取消收藏。

点击左下角「查看 / 编辑」：

- 在「单词与释义」页查看翻译、筛选、批量添加或删除单词，也可编辑完整词表和分组。
- 单击选择一项，按住 **Ctrl** 选择多项，按住 **Shift** 连续选择，再点击「删除选中」。
- 在「编辑词本」页修改名称和简介。完成后点击「保存到云词本」。

删除全本所有单词时，会要求额外确认是否删除整个云词本。

### 添加到今日新学

在词条页点击「今日新学」，按弹窗提示，先到「墨墨背单词 → 我的 → 学习数据同步 → 学习数据自动同步」开启同步，再确认添加。

加入今日新学只是安排学习，不代表已经背过。已学过的词不会通过此功能重置成新词；若手机端尚未显示，请先检查墨墨 App 的同步状态。

## 在其他软件中查词或翻译

在浏览器、文档等软件中选中文本，**连续两次按 Ctrl+C**，即可唤起墨墨搜词。软件会根据内容查询单词、中文反查或翻译段落。

也可以复制文本后按 **Ctrl+Alt+D**，或点击软件左侧的「段落翻译」手动输入内容。

| 默认快捷键 | 操作 |
| --- | --- |
| Ctrl+L | 聚焦搜索框 |
| Ctrl+Alt+D | 唤起软件并处理剪贴板内容 |
| Ctrl+Alt+S | 选择屏幕区域并识别文字 |
| Ctrl+Enter | 加入或移出当前云词本 |
| Ctrl+H | 打开查词历史 |
| Ctrl+T | 打开段落翻译 |
| Alt+← / Alt+→ | 后退 / 前进 |

可在「设置 → 快捷键」中更换组合键；连续两次 Ctrl+C 的功能可在常规设置中关闭。

## 鼠标取词与截图翻译

将鼠标移到网页、PDF 或静态图片中的英文单词上并停留，浮窗会显示释义和助记，移开后收起。支持可访问的超链接和文本框；图片中的英文通过本机 OCR 识别。在「设置 → 鼠标取词」中可调整延迟、组合键、字号和半透明效果。

按 **Ctrl+Alt+S** 拖选屏幕区域，按 Esc 取消。识别到一个英文单词时直接打开词条；识别到段落时进入可编辑的翻译页面。原图仅在本机处理，在线翻译只接收识别出的文字。

模糊字体、受保护内容或特殊绘制的页面可能无法识别；取词只支持英文。建议在图片和视频画面中配合按键取词，减少意外触发。

## 新手引导与更新

首次启动会在实际页面上聚焦并高亮对应功能，旁边显示操作说明，可随时跳过。需要重看时，打开「设置 → 常规 → 查看新手引导」。

「设置 → 软件更新」可手动检查 GitHub 正式版，或开启自动检查和下载，并选择检查频率。下载完成后由你选择更新并重启。

## 常见问题

**哪些功能可以离线使用？**

查词、中文反查、相关词、本地助记、历史记录和本机发音可以离线使用。真题例句、段落翻译需要联网；墨墨云功能还需要登录。段落翻译优先使用 DeepL，连接失败或服务暂不可用时自动使用备用服务，并显示实际来源；输入文字会发送给所用的在线翻译服务。

**更新或卸载会删除自己的助记吗？**

个人助记、查词历史和账号信息保存在 `%LOCALAPPDATA%\MemoLex`，与软件安装目录分开。正常更新或卸载不会删除这些数据；便携版也使用这一目录。换电脑前可备份个人助记，账号需要在新电脑重新登录。

**点击关闭后，软件为什么还在运行？**

首次关闭时可以选择退出或最小化到托盘，并记住选择。最小化到托盘后，点击托盘图标可恢复；需要彻底退出时，右键托盘图标选择「退出」。关闭方式可在常规设置中调整。

**云词本加载失败怎么办？**

先检查网络和账号状态。若提示登录失效，请在账号设置重新登录；查词和本地助记仍可离线使用。
