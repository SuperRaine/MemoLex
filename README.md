# 墨墨搜词 MemoLex

适用于 Windows 的英汉查词工具，支持离线查词、中文反查、助记、真题例句和墨墨云词本。

**本软件为个人开发的非官方工具，与「墨墨背单词」无隶属关系。**

[下载软件](https://github.com/SuperRaine/MemoLex/releases/latest) · [使用说明](使用说明.md) · [问题反馈](https://github.com/SuperRaine/MemoLex/issues/new/choose)

## 下载与安装

支持 **Windows 10 / 11（64 位）**，已包含运行环境、离线词库和本地助记。

| 版本 | 使用方法 |
| --- | --- |
| [安装版](https://github.com/SuperRaine/MemoLex/releases/download/v1.4.0/MemoLex-1.4.0-Windows-x64-Setup.msi) | 双击安装，按向导操作即可。 |
| [便携版](https://github.com/SuperRaine/MemoLex/releases/download/v1.4.0/MemoLex-1.4.0-Windows-x64.zip) | 完整解压后，运行 `MemoLex/MemoLex.exe`。 |

登录和海词词典需要网页组件，缺少时按提示联网安装即可。

## 可以做什么

- **查词与中文反查**：输入英文单词、短语或中文含义，查看释义、近义词、形近词和派生词。
- **助记与例句**：查看或编辑助记，按考研、四级、六级、高考筛选真题例句。
- **墨墨云功能**：收藏和管理云词本，添加今日新学，保存并切换多个账号。
- **阅读与翻译**：鼠标取词、截图翻译、段落翻译；点击英文单词可查看释义。
- **快捷操作**：支持连续两次 Ctrl+C 查词、自定义快捷键、海词词典和考试倒计时。

## 开始使用

在搜索框输入英文或中文，按 Enter 查词。需要使用云词本或今日新学时，在「设置 → 墨墨账号」中登录。

首次打开可跟随新手引导了解常用功能，也可随时跳过。更多操作见[使用说明](使用说明.md)。
