# 墨墨搜词 MemoLex

Windows 英汉查词工具，支持离线查词、中文反查、助记、真题例句和墨墨云词本。

**本软件为个人开发的非官方工具，与「墨墨背单词」无隶属关系。**

[下载软件](https://github.com/SuperRaine/MemoLex/releases/latest) · [使用说明](使用说明.md) · [问题反馈](https://github.com/SuperRaine/MemoLex/issues/new/choose)

## 下载

支持 **Windows 10 / 11（64 位）**，自带运行环境、离线词库和本地助记。

网页登录和海词页面使用系统网页组件；缺少时，按提示联网安装一次即可。

## 主要功能

- **离线查词**：英文单词、短语和中文反查，提供近义词、形近词与派生词。
- **助记与例句**：查看和编辑本地助记，按考研、四级、六级、高考筛选真题例句。
- **墨墨云功能**：管理云词本、收藏单词、添加今日新学，支持切换账号。
- **阅读与翻译**：鼠标悬停取词、截图翻译、段落翻译，点击英文单词继续查词。
- **快捷操作**：连续两次 Ctrl+C 唤起查询，支持自定义全局快捷键、海词词典和考试倒计时。

## 开始使用

在搜索框输入英文或中文含义，按 Enter 查询。需要云功能时，在「设置 → 墨墨账号」中完成官方登录。

首次启动可跟随新手引导熟悉功能。详细操作见[使用说明](使用说明.md)。
