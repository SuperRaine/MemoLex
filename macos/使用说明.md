# 墨墨搜词 Mac 版

适用于 macOS 13 或更高版本，原生支持 Apple Silicon 和 Intel Mac，内置离线词库与本地助记，开箱即用。

## 安装与开始使用

打开 DMG，将「MemoLex」拖到「应用程序」后启动。

当前发行包尚未经过 Apple 公证。首次打开如被系统阻止，请确认从官方发布页下载，再到「系统设置 → 隐私与安全性」选择「仍要打开」。

在左侧输入英文或中文，按回车查词；拼写有误时自动给出相近建议。点击单词建议可直接切换释义并保留搜索框内容；开启「先回想」模式后，再次查到已查过的单词会先遮住释义 2 秒，按空格或回车查看答案。

## 助记、词根与我的例句

- **词根拆解、近义辨析与形近区分**：点击词根、词缀卡片可单选或多选查看构词含义、展开同根词家族，并可点击「练这组」对比辨析同源词；展开相关词中的「近义词」「形近词」后，可一键打开「近义辨析」或「形近区分」对比词性边界、语义侧重、常见搭配与差异字母。
- **真题例句与我的例句**：按考试类型筛选真题例句并整句朗读；支持从真题、翻译一键收藏或自建、编辑「我的例句」（含译文、来源与标签）并与墨墨云端双向同步；点击左侧栏「我的例句」可统一检索、筛选并开启四选一语境填空自测（自动过滤可同义替换的混淆项，含辨析解析、进度自动保存与重置及错题重练）。
- **学习统计与错题本**：点击左侧栏「学习统计」查看近 7 天查词趋势、最常复查的词与错题入口；点击「错题本」管理全部待巩固错词与拼错单词（有新错题自动收录时显示红点提醒，打开查看后自动消失）。

## 墨墨账号、云词本、错题本与卡片自测

在「设置 → 墨墨账号」登录墨墨官方账号，支持多账号保存与随时切换。登录后可管理云词本、添加「今日学习」新词、浏览顽固单词。请在墨墨 App 中开启「我的 → 学习数据同步 → 学习数据自动同步」，保持状态及时更新。

顽固单词、云词本与「错题本」均支持「卡片自测」，提供「翻卡」与「拼写默写」双模式：支持自动朗读、逐字母提示与拼对自动翻面；拼写出错时自动记下易错位置，下次针对性巩固。

- **错题本自动巩固**：在例句四选一、卡片自测、拼写默写、同根辨析中答错或拼错会自动收入错题本，抽测时常错词优先出现，多次答对后自动移出。
- **随机抽测与拼写抽测**：在错题本中可按重点易错、拼写错误、例句/辨析或卡片忘记筛选，一键发起「随机抽测」（卡片模式）、「拼写抽测」或批量加入云词本。

## 取词与翻译

- **悬浮快查条**：按 `⌃⌥F` 在任意界面呼出轻量快查条，支持离线查词、朗读与收藏，点击外部自动收起。
- **鼠标取词**：在设置中开启后，将鼠标停在英文单词上即可查看释义与助记，浮窗内支持发音和一键收藏。网页、PDF 和图片中的英文均可识别。
- **截图翻译**：点击左侧按钮或按 `⌃⌥S` 框选。单个词直接查词，段落自动进入翻译页；按 Esc 取消。
- **剪贴板查词**：按 `⌃⌥D`，或在设置中开启「连按两次 ⌘C」。
- **段落翻译与生词提取**：支持英汉双向翻译，点击单词查词并收藏所在例句，翻译下方自动提取重点生词支持一键批量加入云词本。

取词需要「辅助功能」权限，图片取词和截图翻译需要「屏幕录制」权限，可在「设置 → 系统权限」查看与重置。图片文字识别在本机完成，段落翻译需要联网。

## 常用快捷键

| 操作 | 快捷键 |
| --- | --- |
| 全局悬浮快查条 | `⌃⌥F` |
| 全局查询剪贴板 | `⌃⌥D` |
| 全局截图翻译 | `⌃⌥S` |
| 聚焦搜索框 | `⌘L` |
| 查词历史 | `⌘Y` |
| 前进 / 后退 | `⌘]` / `⌘[` |
| 段落翻译 | `⌘T` |
| 设置 | `⌘,` |

前三项可在设置中更改。首次打开可跟随新手引导，也可跳过。

## 倒计时、缓存清理与更新

- **考试倒计时**：在「设置 → 常规」开启，支持下拉或直接输入考试日期。
- **数据与缓存**：在「设置 → 数据与缓存」可按类别查看并清除查词历史、收藏例句、拼写易错记录、错题本记录、自测进度及临时缓存；清理不会退出账号，也不会删除本地助记或云词本。
- **更新与卸载**：在「设置 → 软件更新」检查并安装新版本，或展开「卸载软件」进行卸载（可勾选「保留用户资料」）。云端数据不受影响。

本软件为个人开发的非官方工具，与「墨墨背单词」无隶属关系。
