# 墨墨搜词 Mac 版

适用于 macOS 13 或更高版本，同时支持 Apple Silicon 和 Intel Mac。已包含运行环境、离线词库和本地助记。

## 安装与开始使用

打开 DMG，将「MemoLex」拖到「应用程序」后启动。

当前发行包尚未经过 Apple 公证。首次打开如被系统阻止，请确认从本项目发布页下载，再到「系统设置 → 隐私与安全性」选择「仍要打开」。

在左侧输入英文单词或中文含义，按回车查词。点击释义、助记或例句中的英文可跳转；标题栏箭头用于前进、后退。

在「设置 → 常规」开启考试倒计时。年、月、日可以分别下拉选择、直接输入，或用 ↑ ↓ 调整。

## 墨墨账号

在「设置 → 墨墨账号」登录墨墨官方账号，完成后自动保存登录信息。可保存多个账号并切换，登录过期时会提醒。登录信息保存在 Mac 钥匙串。

登录后可收藏到云词本、编辑词表、添加今日新学、查看顽固单词。请在墨墨背单词中开启「我的 → 学习数据同步 → 学习数据自动同步」，保持学习状态及时更新。

## 取词与翻译

- **鼠标取词**：在设置中开启后，将鼠标停在英文单词上。网页、PDF 和图片中的英文均可识别。
- **截图翻译**：点击左侧按钮，或按 `⌃⌥S` 框选。单个词直接查词，段落进入翻译；按 Esc 取消。
- **剪贴板查词**：按 `⌃⌥D`，或在设置中开启「连按两次 ⌘C」。
- **段落翻译**：点击左侧按钮，输入文字后联网翻译。

取词需要「辅助功能」权限，图片取词和截图翻译需要「屏幕录制」权限。可在「设置 → 系统权限」查看。图片文字识别在本机完成，段落翻译需要联网。

升级后旧授权失效时，在「设置 → 系统权限」点击对应权限的「重新授权」。在系统设置允许当前版本后，退出并重新打开软件。若系统设置仍显示旧条目，可移除该条目，再用「＋」添加当前的 MemoLex App。

## 常用快捷键

| 操作 | 快捷键 |
| --- | --- |
| 全局唤起查词 | `⌃⌥F` |
| 全局查询剪贴板 | `⌃⌥D` |
| 全局截图翻译 | `⌃⌥S` |
| 聚焦搜索框 | `⌘L` |
| 查词历史 | `⌘Y` |
| 前进 / 后退 | `⌘]` / `⌘[` |
| 段落翻译 | `⌘T` |
| 设置 | `⌘,` |

前三项可在设置中更改。首次打开可跟随新手引导，也可跳过。

## 更新与卸载

发现新版时默认只提醒，点击后下载。下载完成后，在「设置 → 软件更新」点击「更新并重启」。也可在这里更改检查间隔、下载源和自动下载选项。

在「设置 → 软件更新」展开「卸载软件」。如果想保留本机资料，请先勾选「保留用户资料」。云端数据不受影响。

本软件为个人开发的非官方工具，与「墨墨背单词」无隶属关系。
